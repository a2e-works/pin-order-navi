# ピン順ナビ

指定したピンの位置を順番に回るカーナビWebアプリです。

## 機能
- ルートの保存・複数管理（よく使うピンの組み合わせを名前をつけて保存）
- 住所検索または地図タップでピンを追加
- 現在地からピンを順番に音声＋地図でナビゲーション（右左折・分岐・ラウンドアバウトの案内）
- 通話などでアプリが裏に回った後、復帰時に自動でルート再計算

## 使用技術
- Leaflet.js + OpenStreetMap（地図表示）
- Nominatim（住所検索・逆ジオコーディング、無料）
- OSRM（経路計算、無料）
- ブラウザの Geolocation API / Web Speech API
- Claude Artifacts の window.storage API（ルートの永続保存）

## 使い方
`index.html` をブラウザで開くだけで動作します（GitHub Pagesでも公開可能）。

## 制限事項
- 車線案内（レーンガイド）はありません
- 画面ロック中や通話中は音声案内が止まる場合があります
- 保存データはブラウザ単位（端末・ブラウザごと）です
