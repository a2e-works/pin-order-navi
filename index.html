設定

Googleマイマップ連携の設定
Googleマイマップ（mymaps.google.com）に保存したピンを取り込むには、Google Cloud ConsoleでOAuthクライアントIDを1つ作成し、下に貼り付けてください。クライアントIDは公開情報で、これ自体は秘密情報ではありません。
  1. Google Cloud Console（認証情報）を開き、プロジェクトを作成
  2. 「Google Drive API」を有効化
  3. OAuth同意画面を設定（テストユーザーとしてご自身のGoogleアカウントを追加）
  4. 認証情報 → OAuthクライアントID → アプリケーションの種類「ウェブアプリケーション」
  5. 「承認済みのJavaScript生成元」に、このアプリを公開しているURL（例：https://あなたのユーザー名.github.io/リポジトリ名/）を追加
  6. 発行された「クライアントID」（xxxxx.apps.googleusercontent.com の形式）を下に貼り付けて保存
